# ✨ Code of Conduct ✨

Welcome to the **AI Resume Analyzer** repository!

We are committed to creating a welcoming, respectful, inclusive, and productive environment for everyone who contributes to this project.

Whether you contribute code, documentation, ideas, bug reports, testing, or feedback, your participation is appreciated.

---

## 🎯 Core Values

![Quality Badge](https://img.shields.io/badge/Quality-First-orange?style=flat-square)

- **🌈 Inclusive** — We welcome contributors from all backgrounds and experiences.
- **🤝 Respectful** — Treat everyone with professionalism, kindness, and respect.
- **💬 Collaborative** — Share ideas, provide constructive feedback, and work together.
- **🏆 Supportive** — Help other contributors learn, improve, and succeed.
- **❤️ Empathetic** — Be patient and considerate when communicating with others.

---

## 🚫 Unacceptable Behavior

The following behaviors are not acceptable:

- **💢 Harassment or discrimination** based on personal characteristics.
- **💬 Offensive, abusive, or inappropriate language.**
- **🔒 Sharing someone's private or personal information without permission.**
- **🚷 Bullying, trolling, intimidation, or deliberate disruption.**
- **⚠️ Personal attacks, threats, or hostile behavior.**
- **📢 Repeated unwanted communication or inappropriate content.**

We expect all contributors to maintain a professional and respectful environment.

---

## 🛡️ Code of Conduct Enforcement

Project maintainers are responsible for maintaining a safe and respectful community.

If you experience or witness unacceptable behavior, please report it through the project's **GitHub Issues** or **GitHub Discussions**.

When reporting an issue:

1. Clearly describe what happened.
2. Provide relevant context.
3. Include links or screenshots when appropriate.
4. Avoid sharing unnecessary personal information.

Reports will be reviewed appropriately and handled with discretion.

## 🤝 Be Respectful

Everyone's contribution matters.

Please:

- Use respectful and inclusive language.
- Listen to different opinions and perspectives.
- Give constructive feedback.
- Focus criticism on the code, idea, or implementation rather than the person.
- Be patient with new contributors.
- Avoid mocking or belittling others.
- Assume good intentions unless there is clear evidence otherwise.

### Example

Instead of:

> "This code is terrible."

Prefer:

> "This implementation could be improved by separating this logic into smaller functions."

Constructive feedback helps everyone improve.

## 💬 Be Collaborative

AI Resume Analyzer is built through collaboration.

- **🙌 Ask for help when you need it.**
- **😄 Help others when you can.**

## ⚙️ How You Can Contribute

We welcome contributions to **AI Resume Analyzer**.

Before contributing:

1. **Fork the repository.**
2. **Create a dedicated branch** for your changes.
3. Make your changes carefully.
4. Test your changes locally.
5. Follow the project's coding style.
6. Write clear and descriptive commit messages.
7. Update documentation when necessary.
8. Submit a **Pull Request (PR)**.
9. Clearly explain what your PR changes and why.

### Good Commit Message Examples

```text
Add resume skill extraction improvements
Fix LinkedIn job search filtering
Improve dashboard analytics
Update resume analyzer documentation
Fix Streamlit deployment configuration
